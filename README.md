# Frontend Developer Portfolio (Next.js 15 + React 19 + TypeScript)

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Edit your name, contact details, projects, experience, pricing and FAQs in `lib/data.ts`.
Styles are in `app/globals.css`. Deploy for free on Vercel (import the repo, no settings needed).
